# Security policy

This repository is the first-party Bynk registry service. It shares
[`bynk-lang/bynk`'s security policy](https://github.com/bynk-lang/bynk/blob/main/SECURITY.md).

**Please do not report security vulnerabilities through public GitHub issues.**
Report them privately through GitHub's private vulnerability reporting on
`bynk-lang/bynk`: <https://github.com/bynk-lang/bynk/security/advisories/new>.
Say that the report is about the registry service.

That route is also the one for **malware in a published package**, and for a
**legal takedown request**. An operator acts on it with the takedown described
in the README, "Takedowns". A **dispute over an organisation name** isn't a
security matter: open an issue in this repository.
